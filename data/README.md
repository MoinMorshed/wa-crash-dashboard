# Data

The raw data is **not included** in this repository. The crash, vehicle, and roadway files come from the Highway Safety Information System (HSIS), which provides data under a use agreement that does not allow redistribution.

To reproduce the analysis, request Washington State data (2002 accident, vehicle, and roadway files) from HSIS at https://highways.dot.gov/research/safety/hsis and place the files in this folder. The WSDOT historic state route shapefile used for linear referencing is available from WSDOT's GIS data portal.
